# 轴心与朝向规范（origin-rules）

> 精修脚本（refine）与人工精修的**强制执行标准**。
> 权威消费方：tbg-assets `docs/DESIGN.md` 第 5 节。本文件是它的实施细则，冲突时以 DESIGN.md 为准。

## 1. 通用规则（所有资产）

| 项目 | 标准 |
|---|---|
| 单位 | 1 unit = 1 m，导出前 Apply All Transforms |
| 轴向 | +Y 向上，**-Z 朝前**（glTF / Godot 惯例） |
| 轴心默认 | 底部中心（bottom-center）：X/Z 取包围盒中心，Y 取包围盒最低点 |
| 网格吸附 | 0.5 m 基础网格；墙类宽度必须 2 m 或其整数倍 |
| 法线 | 重算外侧（Recalculate Outside），无翻转面 |

## 2. 分品类细则

### components/ 构件

| 子类 | 轴心 | 朝向约定 | 备注 |
|---|---|---|---|
| roof 屋顶 | 屋面**下沿**中心（底面中心） | 正脊沿 X 轴展开，檐口正面朝 -Z | 重檐同规则；单檐/重檐在 id 后缀区分（-single / -double） |
| wall 墙 | 底边中点 | 墙面外侧朝 -Z，长轴沿 X | 宽 2 m 模数，横向拼接 |
| pillar 柱 | 底面中心 | 无方向性（雕刻面朝 -Z） | 含柱础时轴心取柱础底 |
| base 台基/踏跺 | 底面中心 | 踏跺下行方向朝 -Z | 须弥座无方向性 |
| door-window 门窗 | 底边中点 | 同 wall，外侧朝 -Z | 与墙同宽可互换嵌入 |
| railing 栏杆 | 底边中点 | 长轴沿 X，外侧朝 -Z | 两端需 continue 型 socket |
| bracket 斗拱 | 底面中心 | 出跳方向朝 -Z | hero 件专用 |

### buildings/ 整栋

| 项目 | 标准 |
|---|---|
| 轴心 | 台基/地面接触面的底面中心 |
| 朝向 | **正立面（大门所在面）朝 -Z** |
| 备注 | 自带台基时轴心含台基 |

### props/ 道具

- 轴心：底面中心（悬挂类如灯笼：轴心在**悬挂点**，Y 取最高点）
- 朝向：正面（铭纹、开关面）朝 -Z

### nature/ 自然

- 树：轴心=树干底部中心
- 石/假山：底面中心，无方向性
- 植物：种植点（底面中心）

### terrain/ 地形

- 地面铺装：轴心=地块中心（X/Z 中心，Y 取**顶面**为 0，方便对齐地面高度）
- 崖壁/水面：底面中心；平铺件严格对齐 2 m 网格

## 3. 精修脚本执行清单

refine 脚本按以下顺序执行，每步可独立跳过（`--skip`）：

1. 导入模型 → 2. 单位归一（米，Apply Transforms）→ 3. 法线重算 → 4. 按上表旋转至标准朝向 → 5. 轴心移至规定位置 → 6. 材质映射（material-map.json）→ 7. 导出 GLB（+Y up）

## 4. 验收检查

- [ ] Godot 中原点实例化后，资产"站"在地面上，不飘不陷
- [ ] 两件同类资产并排摆放时朝向一致
- [ ] 墙与墙 2 m 网格吸附拼接无缝
- [ ] 屋顶放在墙顶 socket 时檐口朝外
