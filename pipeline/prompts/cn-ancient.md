# cn-ancient 套件提示词模板

> 用法：复制对应分类模板，只替换 `【主体】` 和尺寸描述，其余一字不动——保证全库风格统一。
> **生成单位 = 配方，不是单件**：按第五节"建筑配方"整组生成构件，避免拼不起来的孤儿件。
> **生成源通用**：模板同样适用于 Tripo CLI 和混元3D（网页文生/图生，面数选 500k，贴图 2K 足够）；混元路线把提示词直接粘进网页输入框即可。
> 所有命令**直接出 GLB**：`--model tripo-p1 -p face_limit=15000 -p texture=true -p pbr=true`（构件/民居/整栋）。**别用 `--for game-mobile/game-pc`**——它们会触发 `convert:FBX`，多扣 10 积分且只给 FBX。输出到工作区 `_raw/`（入库前先精修，见 AGENTS.md）。
> **低模：** `--model tripo-p1`（= P1-20260311，face_limit 50–20000）+ `-p texture=true -p pbr=true`（直接出 GLB）。**唯一地标 hero** 用 `--model tripo-v3.1`（高精度 + detailed，更费积分，配 LOD）。
> 想更小面数 / 真实米制尺寸 / 更小体积，追加 `-p face_limit=… -p auto_size=true -p compress=geometry`。
> **两类：** 组件/民居/整栋（可实例化）→ `game-mobile`（P1 低模）；**唯一地标 hero** → `game-pc`（v3.1 高清+detailed，更费积分，配 LOD）。若 hero 想更省，用 `game-mobile` 出低模再烘焙。

## 全局风格锚（拼进每条提示词）

```
中国古代建筑风格，修仙武侠题材，青瓦木构，飞檐翘角，造型干净，游戏低模
```

**负面约束**（口语化写进提示词，Tripo 无单独 negative 参数）：

```
不要现代元素，不要人物，不要文字招牌，不要背景环境，单体孤立物件
```

## 多视图生成（有参考图时，最精确）

当你有同一物体的正/左/背/右参考图时用多视图，比纯文本/单图更准。命令：

```bash
tripo make front.png left.png back.png right.png --model tripo-p1 -p face_limit=15000 -p texture=true -p pbr=true -n 2 -o _raw/components
```

- **传 2–4 张**，必须含**正面**，其余可省但至少 2 张；缺的**直接不传**（CLI 不认空串）。
- 视图识别：文件名含 `front/back/left/right` 或 `前/后/左/右` 自动对应；否则按 **[正,左,背,右]** 位置补位（第一张必须是正面）。
- 图片：同一物体、一致光照；`PNG/JPEG/WebP`；≥256×256px。

**模型（P 系列）**：
- 低模：`--model tripo-p1`（= `P1-20260311`，面数 50–20000）。
- P2（四边面，preview）：CLI 0.3.1 暂无 `tripo-p2` 别名，可用 `--model P2-20260801`（服务端接受时），或 `--param quad=true`（仅 P2 生效）。

**参数**：`-p <key=value>` 可反复传：
```bash
tripo make front.png right.png --model tripo-p1 -p face_limit=12000 -p auto_size=true -p compress=geometry -p model_seed=42 -n 2 -o _raw/components
```

## 一、构件模板（component，无贴图，30 积分）

构件用于拼装，必须**单体、正交比例、无贴图**，材质入库后在 Blender/Godot 挂共享材质。

```bash
tripo make "【主体，含尺寸与形制】，中国古代建筑风格，青瓦木构，造型简洁规整，游戏低模，单体孤立物件，无底座无地面，不要人物不要背景" --model tripo-p1 -p face_limit=15000 -p texture=true -p pbr=true -n 2 -o _raw/components
```

分类细化：

### roof 屋顶
```
中式【悬山/歇山/庑殿/攒尖/卷棚】顶【单檐/重檐】，宽【6】米进深【4】米，青瓦屋面，屋脊完整，飞檐翘角，木构屋檐下可见椽子
```
要点：必须写死宽高尺寸和形制名词；民居屋顶不要斗拱，殿宇屋顶写"檐下斗拱"。

### wall 墙体
```
中式木构建筑【实墙/花格窗墙/排门墙】，宽2米高3米，正面视角规整对称，白墙木框
```
要点：宽高必须写 2×3m；强调"规整对称"避免 Tripo 自由发挥。

### pillar 柱
```
中式【木圆柱/盘龙石柱】，高【3/4】米，带石柱础，竖直单体
```

### door-window 门窗
```
中式【隔扇门四扇/木板门带铜门环/步步锦棂格槛窗/月洞门】，宽2米，规整对称
```

### railing 栏杆
```
中式【寻杖石栏杆带望柱头/木栏杆】，一段宽2米，直线段，两端可续接
```

### props / nature（无贴图件）
```
【宫灯/石狮/香炉/丹炉/迎客松/竹丛……】，中式古风，造型经典，单体孤立物件
```

## 二、整栋建筑模板（mass，标准贴图，40 积分）

整栋用于远景铺量 / 可实例化（客栈、民居、铺面），**带贴图一次到位**，用 `game-mobile`（P1 低模 + face_limit 15000）：

```bash
tripo make "【建筑描述，含层数/屋顶形制/材质色彩】，中国古代建筑风格，完整单体建筑，游戏低模带贴图，不要人物不要现代元素" --model tripo-p1 -p face_limit=15000 -p texture=true -p pbr=true -n 2 -o _raw/buildings
```

示例（客栈）：
```
两层中式客栈，悬山顶青瓦，一层排门店铺二层木栏杆走廊，白墙朱柱，檐下挂红灯笼，完整单体建筑
```

## 三、英雄件模板（hero，唯一地标 → game-pc / v3.1 高清，50-60 积分）

英雄件 = 全场景独一无二的地标（主城牌楼、仙宫大殿），**用 `game-pc`**（v3.1 高精度 + detailed），并配 LOD；先出概念图再图生：

```bash
# 1. 先用图像工具产出概念图，存 concept/
#    概念图要求：正立面 3/4 视角、纯白背景、无文字
# 2. 图生 3D（game-pc = v3.1 高清；⚠️ 更费积分，配 LOD）：
tripo make ./concept/bld-dian-hall-hero.png --model tripo-v3.1 -p texture_quality=detailed -p texture=true -p pbr=true -n 2 -o _raw/hero
# 3. 记录 seed 与 task id 到该资产 source.json
```

概念图提示词锚：
```
中式重檐庑殿大殿，须弥座台基，斗拱层叠，青瓦朱柱，气势恢宏，游戏概念设计图，纯白背景，3/4 正立面视角
```

## 四、尺寸速查（提示词里必须写死）

| 构件 | 尺寸 |
|---|---|
| 墙/门窗/栏杆单元 | 宽 2m × 高 3m |
| 殿宇柱 | 高 4m；民居柱 高 3m |
| 民居屋顶 | 宽 6m × 进深 4m |
| 店铺屋顶 | 宽 6-8m |
| 台基 | 高 0.5m（民居）/ 1m（殿宇） |
| 地面铺装 | 2m × 2m |

## 五、模数咬合规则（构件能拼起来的关键）

生成任何构件前，先确认它在网格里的咬合关系。**所有尺寸都是 2m 模数的推导结果**：

```
面宽方向：开间数 N × 2m（墙/门窗/栏杆都是 2m 单元，N 开间 = N 个单元）
进深方向：民居 4m（2 柱距）/ 殿宇 6-8m
高度方向：台基 0.5/1m + 柱高 3/4m + 屋顶（出檐另算，入库时含在屋顶件内）
```

**咬合 checklist：**

| 关系 | 规则 |
|---|---|
| 屋顶宽 ↔ 面宽 | 屋顶宽 = 开间数 × 2m + 两侧出檐（悬山/硬山出檐已含在屋顶件宽度内，提示词写柱网面宽即可） |
| 墙单元 ↔ 开间 | 每开间正面 = 1 块墙/门/窗单元（2m），三开间 = 3 单元 |
| 柱 ↔ 开间 | 三开间 = 前檐 4 柱 + 后檐 4 柱（两端共用） |
| 台基 ↔ 柱网 | 台基平面 = 柱网外扩 0.5m/边；台基顶面 = 室内地面 |
| 踏跺 ↔ 台基 | 踏跺宽度 ≤ 明间面宽（2m），置于正门前方 |
| 栏杆 ↔ 台基边 | 栏杆沿台基边缘布置，2m 单元续接 |
| 两层建筑 | 层高 3m/层；二层墙柱对齐一层柱位 |

## 七、配方扩展规则（推导新建筑）

新建筑 = 换开间数 / 换屋顶形制 / 换立面单元的排列组合，**不新增模数**：

1. **换开间**：三开间 → 五开间 = 正立面墙单元 3→5，柱 8→12，屋顶宽 6m→10m。提示词只改尺寸数字。
2. **换屋顶**：民居（悬山/硬山）→ 店铺（歇山）→ 殿宇（歇山带斗拱/庑殿）→ 亭（攒尖）→ 廊（卷棚）。屋顶提示词模板已覆盖全部形制。
3. **换立面**：实墙 / 槛窗墙 / 花格窗墙 / 排门墙 / 隔扇门，五种 2m 单元任意排列组合出不同功能（居住/商业/厅堂）。
4. **加层**：两层 = 一层配方 + 3m 层高再叠一层墙柱 + 栏杆外廊；屋顶永远只在最顶层。

## 八、入库前核对（每配方一次）

- [ ] 屋顶宽度数字 = 开间数 × 2m
- [ ] 所有墙/门/窗提示词均含"宽2米高3米"
- [ ] 同配方构件同批生成，风格锚一字未改
